# Upstream

`prismatic/`, `action_model/` and `memory_vla.py` are copied from
https://github.com/shihao1895/MemoryVLA, branch `openvla-codebase`, commit `d732ea9`.
They are unmodified, except that one full-width colon in a comment of `memory_vla.py` was
replaced by an ASCII colon. The changes this baseline needs are made in `../model.py` and
`../config.py`.

The upstream repository carried no LICENSE file at that commit. Its README credits the
OpenVLA (https://github.com/openvla/openvla) and CogACT (https://github.com/microsoft/CogACT)
codebases it is built on.
